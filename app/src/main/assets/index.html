3 APK তৈরি করুন

অটো বিল্ড (GitHub)
প্রজেক্ট ZIP
APK বানাতে Android বিল্ড টুল দরকার, যা ফোনের ব্রাউজারে চলে না। তাই এই টুল আপনার নিজের ফ্রি GitHub অ্যাকাউন্টে বিল্ড চালিয়ে APK ডাউনলোড লিংক দেয়। আপনার টোকেন শুধু api.github.com-এ যায়, অন্য কোথাও না।
টোকেন বানান: এই লিংকে গিয়ে “Generate token” চাপুন (repo + workflow অনুমতি আগে থেকেই টিক দেওয়া থাকবে)।
  • GitHub-এ লগইন যাচাই
  • রিপোজিটরি তৈরি
  • প্রজেক্ট ফাইল আপলোড
  • বিল্ড চালু করা
  • APK তৈরি হচ্ছে (৩–৬ মিনিট)
এখানে পুরো Android Studio প্রজেক্ট ZIP আকারে নামবে। ZIP-এ GitHub Actions ফাইলও আছে, তাই এক্সট্র্যাক্ট করে যেকোনো GitHub রিপোতে আপলোড করলেই APK বিল্ড হবে। কম্পিউটারে Android Studio থাকলে সরাসরি খুলেও বিল্ড করতে পারেন।

ℹ️ জেনে রাখুন

• APK ইনস্টলের সময় ফোনে “অজানা সোর্স থেকে ইনস্টল” অনুমতি দিতে হবে।
• এটি ডিবাগ-সাইনড APK, ব্যক্তিগত ব্যবহার ও টেস্টের জন্য ঠিক আছে। Play Store-এ দিতে চাইলে আলাদা রিলিজ সাইনিং লাগবে।
• আপনার HTML অ্যাপের ভেতরে ফাইল হিসেবে থাকে, তাই ইন্টারনেট ছাড়াও চলে (CDN লাইব্রেরি ছাড়া)।
• রিপোজিটরি ডিফল্টভাবে Public হয়, যাতে ডাউনলোড লিংক সরাসরি কাজ করে।
